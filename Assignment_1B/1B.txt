Pre-processing:
- the data were kept as it and no grayscale conversion or extreme resizing was applied
    - this was omited because in person re-id, color is one of the critical disctriminative features. Converting to grayscale would destroy this information. Similarly, the image are quite small already (168 x 64) 
        resizing them would further destroy the spatial pattern that deep learning relies on.
- Both non DL and DL were given the same original pixel data. However, the images had to be reshaped (flattened into 1D vectors) for PCA to mathematically process them, the underlying raw pixel values are still   the same. 

Details of non-deep learning and deep-learning: 
The person re id task is an open set retrieval problem.
    Non-Learning Approach (PCA + 1)
        - Principle Component Analysis was used to reduce the 24,576 raw pixel dimensions down to the components that explain 95% of the variance. A 1 Nearest Neighbour approach with (L2) distance to rank the 
            matches was then used to 
        - The PCA model was instaniated with n_componnents = 0.95. This parameter mathematically ensures that the model retains the top principle components responsible for 95% of the variance in the dataset. 
        - By setting the PCA to retain 95% of the variance, the algorithm successfully compressed the feature space from 24,576 raw pixel dimensions down to just 717 principal components. This represents a roughly           97% reduction in data size per image, significantly accelerating the 1-Nearest Neighbor distance calculations while preserving the vast majority of the discriminative visual information
        - With the gallery and probe set sucessfuly transformed onto the new PCA space, a nearest neighbour matching as applied.
            - For every single image in the probe set, the algorithm calculates the L2 (Euclidean) distance between its PCA vectors and the PCA vectors of every image in the Gallery database. Since PCA grouped 
                visually similar images closer together in its mathematical space, a smaller L2 distance indicates a higher likelihood of a match. The algorthm then sorted these distances in ascending order to
                to create a ranked list of predictions
        - The ranked list were aggregated via a Cumulitive Match Characteristic Curve which evaluates the probability that the true matching identity appears within the top N nearest neighbours. 
        - STREGTH, WEAKNESSES AND COMPUTATIONAL CONSIDERATIONS:
            - Strength: This approach was the least computationally intensive. Training the PCA subspace requires no GPU acceleration, and took merely a few seconds to compute, which makes it highly scalable for 
                        larger datasets. 
            - weaknesses: Whilt it is computationally efficient, PCA is severly limited by the constraints of the data. PCA is not shift-invariant. It evaluates the variance strictly based on the fixed pixel 
                        coordinates. If a person stands in a shadow, or turns around to reveal a backpack, the raw pixel intensities change drastically. PCA interprets these spatial changes as entirely different                           identities because it lacks the ability to understand semantic, high-level human features.
    Deep Learning Approach (Triplet Loss):
        - While PCA provided a mathematically stable baseline, its reliance on raw pixel variance makes it highly vulnerable to changes in background, lighting, and body positions. To address this, a deep learnning approached was used. Because the context is an open set retrieval problem, standard classification network cannot be used.
